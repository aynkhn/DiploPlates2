# DiploPlates 2: Electric Boogaloo #

New and improved! Took the Python script and converted into a web tool.

--

A tool to decode diplomatic plates.

In the U.S., diplomatic and consular plates are available to those in specific positions. They are allowed to register their cars with "diplomatic" or "consular" licence plates, which hold information about the country they are from. Enter a plate and the script will return with a country.
